# Dry brush Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port slop-paint's Dry brush (a bristle brush running short of paint) as a new brush type, with Dryness and Taper settings.

**Architecture:** slop-paint's self-contained, tested engine `src/dry-brush.ts` at `917f44f` is copied to `src/core/dry-brush.ts` (its imports `./input` and `./brush` already match this app's `src/core/`). It is wired like Ink: a full-redraw branch in `Canvas.svelte`'s `paintStroke`, a `BrushKind` member, two optional `BrushSettings` fields with defaults, and two gear sliders in `ToolOptions.svelte`.

**Tech Stack:** Svelte 5 runes, TypeScript, Vitest (node, no DOM), Playwright WebKit (`npm run test:ipad`).

**Spec:** `docs/superpowers/specs/2026-10-01-dry-brush-design.md`

## Global Constraints

- `npm run build` (`svelte-check && tsc --noEmit && vite build`): 0 errors, 0 warnings. `npm test` baseline 1610; it only grows.
- Branch `feat/dry-brush` (exists, spec committed). One commit per task; trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not merge, push or deploy.
- The engine is slop-paint's at commit `917f44f`, unchanged: `git -C ../slop-paint show 917f44f:src/dry-brush.ts`.
- Menu label `Dry brush`, value `"dry"`, after Calligraphy. Settings `dryness` (0–100, default 50) and `dryTaper` (0–100, default 10), on brush AND eraser defaults.
- A new full-redraw kind must be excluded from the stamp-state reset (`Canvas.svelte`, `bt !== "smooth" && …`), or it falls through to the stamp engine.
- `test:ipad` needs local port binding: run it with the sandbox disabled.

## Review Focus

1. **The eraser set to Dry brush** — erases in the dry pattern (`destination-out` in the engine), with the eraser's own Dryness/Taper. Pinned in Task 2 by reading `ToolOptions`' shared `stroke` binding and in Task 3's check note.
2. **A translucent Dry stroke over existing art, with alpha lock or draw-behind** — composited once (the engine's scratch canvas), not per hair. Engine-tested in slop-paint; Task 2 passes `settings` by spread so `alphaLock`/`drawBehind` reach it.
3. **A Dry stroke inside a marquee selection** — clipped like Ink (`selection?.applyClip`). Task 2's branch.
4. **Old preferences without `dryness`/`dryTaper`** — load with the defaults (merge in `applyPreferences`). Task 2 adds the defaults.
5. **A mouse stroke** (no pressure, `sizeRange` 1) — draws the nominal width with the dry texture, no crash. Task 3's check uses pen events; the engine tests cover constant pressure.

### Task 3: A Dry stroke in the iPad smoke check

**Files:**
- Modify: `tools/ipad-smoke.mjs` (a block right after the `"no autosave failure warning"` check; the header comment's list)

**Interfaces:**
- Consumes: the brush select `select[title="Brush type"]` with option `"dry"`; the script's `send(steps)` (steps `[type, pointerType, id, t, dy?]` along the stage's diagonal, `dy` a fraction of the stage height) and `line(type, id)` helpers, `check`, `page`, `OUT`.

- [ ] **Step 1: Add the check.**

```js
  // The Dry brush (2026-10-01, from slop-paint): a pen stroke paints, and its texture is broken —
  // along the stroke's middle the Dry stroke leaves unpainted gaps where a Smooth stroke of the
  // same size leaves none. Each on a line of its own (dy), away from the earlier strokes.
  /** Unpainted samples along a stroke's middle: n points at t 0.15…0.85 on line `dy`. */
  const gapsAlong = (dy) =>
    page.evaluate(
      ({ x, y, w, h, dy }) => {
        const c = document.querySelector("div.touch-none.overflow-hidden > div canvas");
        const r = c.getBoundingClientRect();
        const ctx = c.getContext("2d");
        let gaps = 0;
        for (let i = 0; i <= 60; i++) {
          const t = 0.15 + (0.7 * i) / 60;
          const cx = x + w * (0.25 + 0.5 * t);
          const cy = y + h * (0.4 + 0.2 * t + dy);
          const px = Math.round(((cx - r.left) * c.width) / r.width);
          const py = Math.round(((cy - r.top) * c.height) / r.height);
          const [R, , , A] = ctx.getImageData(px, py, 1, 1).data;
          if (A === 0 || R > 200) gaps++; // empty or white paper: no ink here
        }
        return gaps;
      },
      { x: stage.x, y: stage.y, w: stage.width, h: stage.height, dy },
    );
  const brushSelect = page.locator('select[title="Brush type"]');
  await page.keyboard.press("b");
  await brushSelect.selectOption("smooth");
  await send(line("pen", 41).map((s) => [...s, 0.3]));
  await brushSelect.selectOption("dry");
  await send(line("pen", 42).map((s) => [...s, -0.3]));
  await page.waitForTimeout(300);
  await page.screenshot({ path: `${OUT}/5-dry-brush.png` });
  const smoothGaps = await gapsAlong(0.3);
  const dryGaps = await gapsAlong(-0.3);
  check(
    smoothGaps === 0 && dryGaps > 0 && dryGaps < 61,
    `the Dry brush paints a broken, dry stroke (gaps along the middle: dry ${dryGaps}/61, smooth ${smoothGaps})`,
  );
  await brushSelect.selectOption("smooth");
```

If the earlier finger-drag pan left the paper away from those lines (samples read `A === 0` everywhere), find the cause and fix the setup (e.g. take the samples where the stroke was really drawn), not the expectation. Add "a Dry brush stroke" to the header comment's list.
